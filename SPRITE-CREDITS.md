# Sprite credits

The site's default Pokémon sprites are the **Gen 9 Scarlet/Violet front sprites** served from the PokeAPI `sprites` repository through jsDelivr.

Source repository:
https://github.com/PokeAPI/sprites/

PokeAPI's sprite README credits KingOfThe-X-Roads for the generation 9 front_default sprites and notes that the repository hosts the sprite images for application use.

The SBL code does not claim ownership of the Pokémon artwork.
